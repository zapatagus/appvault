# AppVault — catálogo de aplicaciones Android

Sitio estático preparado para GitHub Pages.

## Incluye
- Diseño responsive y moderno.
- Buscador y filtros.
- Fichas individuales.
- Vídeos de demostración.
- Capturas.
- Comparativa.
- Descarga directa de `NetflixMod.apk` y `StreamFlix.apk`.
- Sección FAQ.

## Publicación
1. Crea un repositorio en GitHub.
2. Sube todo el contenido de esta carpeta a la rama principal.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, la rama principal y `/ (root)`.
4. Guarda y abre la URL que GitHub genere.

## Añadir una nueva app
Duplica un bloque `<article class="app">`, cambia textos/rutas y añade una fila en la tabla comparativa.

## Nota
Antes de publicar APKs, confirma que tienes autorización para distribuirlos y que las licencias, marcas, contenido y dependencias permiten esa distribución.
